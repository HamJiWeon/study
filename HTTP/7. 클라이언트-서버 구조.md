## 클라이언트-서버 구조
```text
┌──────────┐  Request ⟶                        ┌──────────┐
|  Client  |───────────────────────────────────|  Server  |
└──────────┘                       ⟵ Response  └──────────┘
```
- Request, Response 구조
- 클라이언트는 서버에 요청을 보내고, 응답을 대기
- 서버가 요청에 대한 결과를 만들어서 응답

**장단점**
- **역할 분리**: 클라이언트는 화면 표기와 요청만, 서버는 데이터 처리와 저장을 담당한다.
- **관리가 편함**: 데이터와 프로그램이 서버에 모여 있어 업데이트나 보안 유지가 쉽다.
- **확장성**: 여러 사용자가 동시에 접속해도 안정적으로 서비스를 나눌 수 있다.
- **단점**: 서버가 멈추거나 고장 나면 모든 클라이언트가 서비스를 쓰지 못한다.
