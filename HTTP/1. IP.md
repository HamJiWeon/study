## IP란 무엇인가?
`IP(Internet Protocol)`란 인터넷이 연결되어 있는 장치들(컴퓨터, 스마트폰, 서버 장비 등)을 식별할 수 있도록 각각의 장비에게 부여되는 고유 주소
> 예를 들어, 친구에게 "Hello, World"라는 문자를 보내고 싶을 때 최소한의 어떠한 규칙으로 인해 갔을 것이다.
> 바로 IP 주소를 부여함으로써 가능해진다.

## IP의 역할
- 지정한 IP 주소(IP Address)에 데이터 전달
- 패킷(Packet)이라는 통신 단위로 데이터 전달

**[Packet](https://docs.tosspayments.com/resources/glossary/packet)**: 네트워크에서 데이터를 주고받을 때 사용하는 데이터 조각

## IP 패킷 정보
- **헤더(Header)**: 데이터를 안전하게 목적지까지 보내기 위해 붙이는 안내 정보(출발지/목적지 주소, 경로 설정 등)
- **페이로드(Payload)**: 실제로 전달하려는 본문 데이터(텍스트, 이미지, 상위 프로토콜 데이터 등)

### Version
`IPv4`, `IPv6`와 같은 버전을 나타낸다.
- `IPv4`:
  - IP version 4의 약자로 전 세계적으로 사용된 첫 번째 인터넷 프로토콜
  주소는 32비트 방식으로, 8비트씩 4자리로 되어 있으며 각 자리는 `.`으로 구분
  - ex.`192.168.1.1`
- `IPv6`:
  - IP version 6의 약자로 `IPv4`의 주소체계를 128비트 크기로 확장한 차세대 인터넷 프로토콜
  16비트씩 8자리로 각 자리는 `:`으로 구분
  - ex. `2001:0db8:0000:0000:0000:ff00:0042:8329`

### Header Length
헤더의 길이를 word 단위로 나타낸다. word는 32bit(4byte)로 현재 `IPv4`의 헤더 길이는 고정되어 있어 version만 알면 자동으로 헤더의 길이를 알 수 있지만, 추후에 프로토콜에 기능이 추가될 수 있기 때문에 들어있는 필드

### Service Type(TOS: Type Of Service)
데이터의 지연 통신효율, 신뢰성의 우선순위를 지정하는 용도이지만 현재는 사용하지 않음

### Packet Length(TL: Total Length)
패킷 전체의 길이를 byte 단위로 나타냄

### Identification
IP 패킷은 보통 여러대의 라우터를 거쳐 전달  
이때 라우터가 패킷을 작은 단위로 분할할 수 있음  
분할된 패킷을 fragment라고 하는데, 목적 호스트에서 fragment가 원래 어떤 패킷 안의 내용인지 판별하는데 identification을 씀

### Flag
패킷 분할에 대한 정보를 3비트로 나타냄
- 첫 번째 비트(RF):
  - 예약된 비트
  - 항상 `0`으로 설정
- 두 번째 비트(DF): 
  - 패킷의 단편화 금지 여부를 결정
  - `1`: 패킷을 단편화하지 마라
  - `0`: 필요시 단편화할 수 있음
- 세 번째 비트:
  - 쪼개진 조각이 더 남아있는지 표시
  - `1`: 뒤에 더 조각난 패킷이 존재
  - `0`: 마지막 조각이거나 단편화되지 않은 유일한 패킷

### Fragment Offset
원본 데이터에서의 fragment의 위치를 byte 단위로 나타냄

### Time to Live(TTL)
패킷이 통과할 수 있는 라우터의 수

### Protocol Type
IP 패킷이 운반하는 데이터의 프로토콜  
- type:
  - `1`: ICMP
  - `6`: TCP
  - `0x11 = 17`: UDP

### Header Checksum
헤더 내용이 바르게 교환되었는지 점검

### Source IP Address
패킷을 보낸 호스트의 IP

### Destination IP Address
패킷을 받는 호스트의 IP

## IP 프로토콜의 한계
- **비연결성**
  - 패킷을 받을 대상이 없거나 서비스가 불능 상태여도 패킷 전송
- **비신뢰성**
  - 패킷이 중간에 사라지거나 순서대로 안 오는 경우
- **프로그램 구분**
  - 같은 IP를 사용하는 서버에서 통신하는 애플리케이션이 둘 이상인 경우
