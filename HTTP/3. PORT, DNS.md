# PORT
## PORT 정의
포트는 운영 체제 통신의 종단점이다. 이 용어는 하드웨어 장치에도 사용되지만,  
소프트웨어에서는 네트워크 서비스나 특정 프로세스를 식별하는 논리 단위이다.

### PORT란?
TCP/IP 패킷 정보를 보면, IP 패킷 안에 [TCP 세그먼트](https://github.com/HamJiWeon/study/blob/main/HTTP/2.%20TCP.md)가 존재한다.  
- **IP**: 목적지 서버를 찾음
- **PORT**: 서버 안에서 돌아가는 애플리케이션들을 구분

> **정리**
> PORT란 같은 IP 내에서 프로세스를 구분해주는 역할을 한다.
> IP: 아파트
> PORT: 동/호수

### 포트의 할당 범위
- `0 ~ 65535`: 할당 가능
- `0~1023`: 잘 알려진 포트, 사용하지 않는 것이 좋음
  - FTP: `20`, `21`
  - TELNET: `23`
  - HTTP: `80`
  - HTTPS: `443`

# DNS
## DNS란?
Domain Name System으로, IP를 우리가 보기 쉽게 만들어 주는 역할을 한다. `ex. www.google.com`

### DNS 작동 원리
```text
┌─────────────────────┐  1. Domain Name(google.com)  ┌───────────────────────────────────────┐
|  Client             |<─────────────────────────────|  DNS Server                           |
|  IP: 100.100.100.1  |─────────────────────────────>|  ┌───────────────┬─────────────────┐  |
└─────────────────────┘    2. res: 200.200.200.2     |  |  Domain Name  |        IP       |  |
          |                                          |  ├───────────────┼─────────────────┤  |
          |  3. conn:                                |  |  google.com   |  200.200.200.2  |  |
          |  200.200.200.2                           |  └───────────────┴─────────────────┘  |
          |                                          └───────────────────────────────────────┘
     ┌────↓─────┐
     |  Server  |
     └──────────┘
```
