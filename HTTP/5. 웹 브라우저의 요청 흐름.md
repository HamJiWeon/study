`https://www.google.com/search?q=hello&hl=ko`라는 URL이 있을 때,  
1. 웹 브라우저가 `www.google.com`를 DNS 서버에 보내서 IP를 조회한다.
2. `https`이니까 포트 정보를 찾아낸다.
3. HTTP 요청 메시지를 생성한다.
```text
GET /search?q=hell&hl=ko HTTP/1.1
Host: www.google.com
```
4. HTTP 메시지를 전송한다. 이전에 했던 [TCP](https://github.com/HamJiWeon/study/blob/main/HTTP/2.%20TCP.md)에 설명이 나와있다.
```
┌─────────────────────────────────────────────────────────────────────┐
|               ┌──────────────────────────────────────────────────┐  |
|               |   Web Browser | Network | Game | Chat Program    |  |
|  Application  |  ┌────────────────────────────────────────────┐  |  |
|               |  |               SOCKET Library               |  |  |      
|               |  └────────────────────────────────────────────┘  |  |
|               └──────────────────────────────────────────────────┘  |
|                                                                     |
|               ┌──────────────────────────────────────────────────┐  |
|               |  ┌─────────────────────┐┌─────────────────────┐  |  |
|               |  |         TCP         ||         UDP         |  |  |
|           OS  |  └─────────────────────┘└─────────────────────┘  |  |
|               |  ┌────────────────────────────────────────────┐  |  |
|               |  |                     IP                     |  |  |
|               |  └────────────────────────────────────────────┘  |  |
|               └──────────────────────────────────────────────────┘  |
|                                                                     |
|               ┌──────────────────────────────────────────────────┐  |
|      Network  |                    LAN Driver                  ┌────────────┐
|    Interface  |                                                |  LAN Card  |  - (Internet) → Server
|               |                   LAN equipment                └────────────┘
|               └──────────────────────────────────────────────────┘  |
└─────────────────────────────────────────────────────────────────────┘
```
5. 웹 브라우저가 만든 HTTP 요청 메시지를 TCP/IP 패킷에 담이 인터넷망으로 보낸다.
6. 그럼 수많은 노드를 통해서 `google.com`의 IP로 전달이 된다.
7. 요청 패킷이 구글 서버에 도착하면 TCP/IP 패킷을 분해하고 HTTP 메시지를 해석을 한다.
8. 검색 엔진을 통해서 hello와 관련된 결과에 한국어로 바꾼다음 데이터를 찾는다.
9. 그럼 서버에서 HTTP 응답 메시지를 만들어낸다. `ex. 200 OK, Content-Type, Content-Length, HTML`
10. 아직까지 왔던 방식으로 서버에서 다시 응답 메시지를 돌려보낸다.
