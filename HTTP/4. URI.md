## URI란?
Uniform Resource Identifier로, 인터넷에 있는 자원을 나타내는 통합 자원 식별자를 말한다.

## URI? URL? URN?
URI는 로케이터(**L**ocator), 이름(**N**ame) 또는 둘 다 추가로 분류될 수 있다.

```
┌─────────────────────────────────────────────────────────┐
|  ┌─────────────────────────┐  ┌──────────────────────┐  |
|  |  URL(Resource Locator)  |  |  URL(Resource Name)  |  |
|  └─────────────────────────┘  └──────────────────────┘  |
|                 URI(Resource Identifier)                |
└─────────────────────────────────────────────────────────┘
```

**URL과 URN**
```
  foo://example.com:8042/over/there?name=ferret#nose  ⟵ URI
  └|┘   └──────|───────┘ └───|────┘ └────|────┘ └|─┘
 scheme    authority        path       query   fragment
  ┌|┐ ┌──────────────────────|─┐
  urn:example:animal:ferret:nose  ⟵ URN
```
URN은 보는 거와 같이 웹 상에서 자원의 위치를 알 수 없어 직접 접근하거나 가져올 수 없다는 단점이 있다.  
그래서 보통 URL만 쓴다.

### URI 단어 뜻
- **U**niform: 리소스 식별하는 통일된 방식
- **R**esource: 자원, URI로 식별할 수 있는 모든 것(제한 없음)
- **I**dentifier: 다른 항목과 구분하는데 필요한 정보

### URL 전체 문법

`scheme://[userinfo@]host[:port][/path][?query][#fragment]`
`https://www.google.com:443/search?q=hello&hl=ko`

- **scheme**
  - `https`
  - 주로 프로토콜 사용
  - 프로토콜: 어떤 방식으로 자원에 접근할 것인가 하는 약속 규칙
    - ex. http, https, ftp 등등
  - http는 80포트, https는 443포트를 주로 사용, [PORT](https://github.com/HamJiWeon/study/blob/main/HTTP/3.%20PORT%2C%20DNS.md)
  - https는 http에 보안 추가(Http Secure)
- **userinfo**
  - URL에 사용자 정보를 포함해서 인증
  - 거의 사용하지 않음
- **host**
  - `www.google.com`
  - 호스트명
  - 도메인명 또는 IP 주소를 직접 사용가능
- **PORT**
  - `:433`
  - 접속 포트
  - 일반적으로 생략, 생략시 http: 80 / https: 443
- **path**
  - `/search`
  - 리소스 경로(path), 계층적 구조
  - ex.
    - `/home/file1.jpg`
    - `/members`
    - `members/100`, `items/iphone12`
- **query**
  - `?q=hello&hl=ko`
  - `key=value` 형태
  - `?`로 시작, `&`로 추가 가능 `?key1=value1&key2=value2`
  - query parameter, query string 등으로 불림, 웹 서버에 제공하는 파라미터. 문자형태
