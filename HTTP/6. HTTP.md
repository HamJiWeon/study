## HTTP란?
**H**yper **T**ext **T**ranfer **P**rotocol로, 인터넷에서 웹 브라우저(클라이언트)와 웹 서버가 서로 데이터를 주고받기 위해 만든 통신 규칙이다.

### HTTP 메시지
- HTML, TEXT
- IMAGE, 음성, 영상, 파일
- JSON, XML(API)
- 등 거의 모든 형태의 데이터 전송 가능
- 서버간에 데이터를 주고 받을 때도 대부분 HTTP 사용

### HTTP 역사
- HTTP/0.9 1991
- HTTP/1.0 1996
- HTTP/1.1 1997년:
  - RCF2068(1997) ⟶ RCF2616(1999) ⟶ RCF7230~7235(2014)
- HTTP/2 2015년: 현재 가장 많이 사용
- HTTP/3 진행중: TCP 대신에 UDP 사용, 성능 개선

### 기반 프로토콜
- **TCP**: HTTP/1.1, HTTP/2
- **UDP**: HTTP/3
현재 HTTP/2 주로 사용

|구분|HTTP/1.1 (1997년)|HTTP/2 (2015년)|HTTP/3 (2022년)|
|---|---|---|---|
|기반 프로토콜|TCP|TCP|UDP(QUIC)|
|전송 방식|텍스트 (순차적)|이진 프레임 (동시화)|이진 프레임 (독립 다중화)|
|연결|속도느림 (매번 3-Way Handshake)|보통 (최초 Handshake 필요)|매우 빠름 (0-RTT 연결 재개)|
|보안 (TLS)|선택 사항|사실상 필수 (브라우저 기준)|프로토콜 자체에 내장 (기본)|
|2026년 기준 점유율|약 27.8%|약 52.2% (가장 대중적)|약 19.8% (성장 중)|

## HTTP 특징
- 클라이언트 서버 구조
- 무상태 프로토콜(stateless), 비연결성
- HTTP 메시지
- 단순함, 확장 가능
