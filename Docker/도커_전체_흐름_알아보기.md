터미널에서 CLI를 통해 Docker를 조작할 수 있다.

처음에 NginX를 설치해보겠다.
>**NginX란?**  
>NginX는 여러 기능을 가진 서버 중 하나이다.
>- 웹 서버(HTML 웹 페이지를 렌더링 시키는 역할)
>- 로드밸런싱
>- 리버스 프록시

### NginX 설치하기
1. 처음에 도커 이미지를 생성한다.
```bash
docker pull nginx
```
2. `docker image ls`를 실행하면 잘 나오는 것을 볼 수 있다.
```bash
nginx:latest   8541484afbc9        259MB         64.3MB
```
3. 컨테이너를 만든다. 없으면 새로 만드는 `run`을 사용한다.
```bash
docker run --name webserver -d -p 80:80 nginx
```
4. `docker ps`와 localhost:80을 해서 봤을 때 잘 나온 것을 볼 수 있다.
