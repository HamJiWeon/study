## Docker Image 명령어
### Image를 다운받기
```bash
docker pull [다운받을 이미지 명]
```
### Image list 확인하기
```bash
docker image ls
```
### Image가 어디서 다운 받아졌는지 확인하기
> `hub.docker.com` > `검색창에 [다운받은 이미지 명]` > `이미지 들어가기`

Tags를 들어가게 되면 이미지의 다양한 버전을 볼 수 있다.  
원하는 버전의 이미지를 다운 받으려면 다음과 같이 터미널에 작성하면 된다.  
ex)
```bash
docker pull nginx:stable-alpine3.19-perl
```
- 이때 `:`을 안 붙이게 되면 자동으로 `:latest`를 적용한다.

## Image 삭제하기
- **컨테이너가 없는 이미지**
```bash
docker image rm [id값 or id 일부 값]
```
- **컨테이너가 있지만 실행되지 않고 있는 이미지**
```bash
docker image rm -f [id값 or id 일부 값]
```
- **컨테이너가 없는 이미지 일괄 삭제**
```bash
docker image rm $(docker images -q)
```
- **중단된 컨테이너 이미지 일괄 삭제**
```bash
docker image rm -f $(docker images -q)
```
