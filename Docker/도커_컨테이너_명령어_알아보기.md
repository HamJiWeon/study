## Docker Container 명령어
```bash
docker create [이미지명]
```
> 이미지를 가지고 컨테이너를 생성한다.
> 이미지를 가지고 있지 않아도 자동으로 다운 받는다.

```bash
docker ps -a
```

```bash
CONTAINER ID   IMAGE       COMMAND                   CREATED          STATUS                      PORTS     NAMES
a661d75d1189   nginx       "/docker-entrypoint.…"   7 seconds ago    Created                               peaceful_maxwell
ad6897824ac4   nginx       "/docker-entrypoint.…"   43 minutes ago   Exited (0) 28 minutes ago             webserver
```
- 컨테이너를 배치는 했는데 실행을 하지 않은 상태이다.

### Container 실행하기
```bash
docker start [아이디 값]
```

하지만 `create`와 `start`는 잘 사용할 일은 없다.  
이 두 개를 합친 명령어가 있다.

```bash
docker run [이미지명]
```
> 이미지 다운 -> 컨테이너 생성 -> 생성된 컨테이너 실행
- `docker run`은 **foreground**에서 실행을 한다.

**foreground란?**
- 내가 실행시킨 프로그램의 내용이 화면에서 실행되고 출력되는 상태
- 실행시킨 프로그램의 상태를 즉각적으로 보내야 하기 때문에 다른 프로그램을 사용할 수 없다.
**background란?**
- 내가 실행시킨 프로그램이 컴퓨터 내부적으로 실행되는 상태
- foreground와 반대로 상태를 확인할 수는 없지만 다른 프로그램을 사용할 수 있다.

그럼 background로는 어떻게 실행할 수 있을까?
```bash
docker run -d [이미지명]
```
